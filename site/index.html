01 · HOW IT WORKS

四步，从爆满到清爽

扫描整盘

分类建议

每一项标注可清理 / 建议迁移 / 待确认 / 正在使用 / 仅统计，并写清"这是什么、删了会怎样"。

05 · SAFETY

为什么敢让它动你的 C 盘

所有不可逆操作都有前置确认和回退路径；删不掉的、看不准的，宁可不碰。

  1. 01按住数秒确认 直接删除、清空回收站、删迁移备份等不可逆操作，都要按住按钮数秒才执行，松手即取消。
  2. 02删前复查占用 删除和迁移前检查目标是否被进程占用，被占用的自动跳过，等程序关闭再处理。
  3. 03迁移五步走 复制 → 校验 → 备份 → 建链接 → 验证，任一步失败自动还原，原数据始终不动。
  4. 04三重校验再删备份 删除迁移备份前校验链接指向与目标数据完整性，通不过不删。
  5. 05首次启动必读 第一次运行先弹使用说明，把所有不可恢复的操作列清楚，再让你动手。
  6. 06只碰本轮扫到的路径 操作范围严格限于本次扫描结果，不临时扩大，不碰计划外目录。
